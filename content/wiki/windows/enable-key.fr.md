# Activation par clé

## Windows 10/11 Professionnel

Clé d'activation : `W269N-WFGWX-YVC9B-4J6C9-T83GX`

### Étapes d'activation

1. Installer la clé de produit :

```cmd
slmgr /ipk W269N-WFGWX-YVC9B-4J6C9-T83GX
```

2. Définir le serveur KMS :

```cmd
slmgr /skms kms8.msguides.com
```

3. Activer Windows :

```cmd
slmgr /ato
```

[Liste de toutes les clés](https://docs.microsoft.com/windows-server/get-started/kms-client-activation-keys)
