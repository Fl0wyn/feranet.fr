# Passer à Windows 11

## Vérifier la compatibilité du PC

Utilisez l'outil officiel pour vérifier si votre PC est compatible avec Windows 11. [Vérifier la compatibilité](https://www.microsoft.com/windows/windows-11#pchealthcheck)

## Forcer la mise à jour sur un PC compatible

Téléchargez l'assistant d'installation de Windows 11 pour forcer la mise à jour. [Télécharger](https://www.microsoft.com/software-download/windows11)

## Forcer la mise à jour sur un PC non compatible

Utilisez le script MediaCreationTool.bat pour contourner les vérifications de compatibilité. [Télécharger](https://github.com/AveYo/MediaCreationTool.bat)
